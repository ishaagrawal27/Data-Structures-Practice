Data-Structures-Practice
This project demonstrates basic Python data structures through four practical problems using lists, dictionaries, and sets. It covers word frequency counting, duplicate removal, student marks analysis, and finding common elements between two lists.

 Overview
This project demonstrates basic operations using Python lists, dictionaries, and sets. Four small problems have been implemented using practical datasets.

 Problems Included

1. Word Frequency Counter
A paragraph containing multiple sentences is processed to count how many times each word appears.
Data structure used: Dictionary
 
2. Duplicate Remover
A list containing repeated numbers is processed to remove duplicate values.
Data structure used: Set

3. Student Marks & Average
Marks of multiple students are stored using a dictionary and lists. The program calculates the total and average marks for each student.
Data structures used: List and Dictionary

 4. Common Elements Between Two Lists
Two lists containing numbers are compared to find the values that occur in both lists.
Data structure used: Set
